# liger-ce-fix

Fused linear cross-entropy (fork of [Liger Kernel](https://github.com/linkedin/Liger-Kernel) 0.8.0) with the
log-space fix for **softmax collapse** from Barron, Gnanapragasam & Tschannen,
*A Fix for Softmax and Cross-Entropy* (arXiv 2610.31642, 2026).
